            Backup erstellen

            Lädt den aktuellen Stand aus Supabase als JSON-Datei herunter. Die mit der App ausgelieferten Lebensmittel sind im Code und nicht Teil des Backups – nur was im Editor geändert, angelegt oder deaktiviert wurde.

            Für Benutzerkonten den Service-Role-Key (Supabase → Settings → API) in .env als SUPABASE_SERVICE_ROLE_KEY=… eintragen und den Editor neu starten.
            Das Backup enthält Gesundheitsdaten aller Nutzer – die Datei sicher und nicht in der Cloud oder im Git-Repository ablegen.

            Backup wiederherstellen

            Beiträge und Lebensmittel aus dem Backup werden auf den gesicherten Stand zurückgesetzt bzw. wieder angelegt. Einträge, die nach dem Backup neu dazugekommen sind, bleiben unverändert. Gelöschte Benutzerkonten werden mit derselben ID neu angelegt (Anmeldung danach über «Passwort vergessen»), fehlende Tagebuch-, Blutzucker- und Sport-Einträge ergänzt – vorhandene bleiben, wie sie sind. Kontakt-Nachrichten können nicht über den Editor zurückgeschrieben werden. Vor dem Wiederherstellen wird automatisch ein Backup des aktuellen Stands heruntergeladen.
